# Образец роликов «живая игра + падающие ноты»

Образец: `reference/ОБРАЗЕЦ-rondo-live.mp4` (итог: `final/rondo-live.mp4`).
Все новые ролики такого типа делаются по нему.

## Что присылает автор
1. Видео игры: телефон на штативе, сверху на клавиатуру, без движения камеры.
   Лучше 1080p/4K и ближе к клавишам (так клавиши на экране чётче).
2. «Вайбовое» фото для верхней части.
3. Название пьесы и что именно сыграно.

## Кадр 1080×1920
| Часть | Высота | Что внутри |
|---|---|---|
| Верх | 0–660 | фото, внизу плавно уходит в тёмный фон |
| Середина | 660–1056 | падающие ноты в цветах фото (сейчас: свеча, крем → янтарь, свечение) |
| Низ | 1056–~1500 | только клавиатура из видео, приближенная к сыгранному диапазону |
| Под клавиатурой | ~1500–1920 | тёмная зона под подпись и кнопки Instagram |

## Правила
- Из видео вырезается только клавиатура: без пюпитра, лаковой панели с отражениями, рук ниже клавиш и пола. Яркость выравнивается, блики приглушаются.
- Ноты и тайминг берутся из записи (моменты нажатий по звуку, высоты сверяются с нотами), колонки нот строятся по клавишам на видео: каждая нота падает точно на нажатую клавишу. Сами клавиши на видео не подсвечиваются.
- Звук записи не используется: тот же набор нот синтезируется роялем Salamander (`scripts/synth.py`).
- CTA шрифтом Cormorant Garamond (`project/public/fonts`): хук в начале поверх фото, в конце «Научись играть это» + «Piano Lab · ссылка в профиле».
- Цвета нот и фона подбираются под фото.

## Код
- `project/scripts/rondo_live.py` — ноты, геометрия клавиш, обрезка видео, фото, звук.
- `project/src/SplitVisualizer.tsx` — композиция (в `Root.tsx`: `RondoLive`).
- Рендер: `npx remotion render RondoLive ../final/rondo-live.mp4`.

# Образец 2: «руки в темноте» (живая игра сбоку)

Образец: `reference/ОБРАЗЕЦ-hands-dark.mp4` (итог: `final/hands-dark-short.mp4`).

## Что присылает автор
Видео игры двумя руками сбоку вдоль клавиатуры, телефон неподвижен, звук живой.

## Правила
- Оригинального фона нет совсем: всё, кроме клавиш и рук, заменяется сгенерированной темнотой (тёплое свечение за клавишами, лёгкий дым снизу). Клавиши — неподвижная маска, руки выделяются в каждом кадре по цвету кожи.
- Лаковая панель рядом с клавишами убирается вместе с её отражениями; посторонние цветные предметы не «прилипают» к краям рук.
- Кадр крупнее исходника, медленный наезд на руки, тёплый тон, лёгкое зерно.
- Звук живой, только очищен (без эха). Старт сразу с сильного момента, длина 20–30 с, конец на завершённой фразе (каденция).
- Наверху крутится пластинка с названием на наклейке (Cormorant Garamond, название неподвижно).
- Хук первые ~3 с вместо пластинки, без сантиментов (сейчас «Дай этой мелодии / 20 секунд»); последние 4 с: «Хочешь сыграть это для кого-то?» + «Научись в Piano Lab · ссылка в профиле».

## Код
- `project/scripts/hands_dark.py` — маска, фон, наезд, звук; затем `vinyl_title.py` — пластинка, хук, CTA.
